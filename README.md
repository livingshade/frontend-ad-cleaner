# Frontend Ad Cleaner

两个可分别加载的 Chrome 扩展，在网页前端替换推广内容，保留原链接。

| 扩展目录 | 版本 | 功能 |
| --- | --- | --- |
| [bilibili-promo-replacer](bilibili-promo-replacer/) | 1.2.0 | B 站推广视频显示为“广告”；直播、番剧、漫画等类别推荐显示为“广告：类别” |
| [zhihu-cleaner](zhihu-cleaner/) | 1.0.3 | 知乎推广和盐选卡片显示为“广告”；隐藏航海家入口和标记，保留赞同人数及按钮 |

B 站类别推荐的“广告：”是显示偏好，不表示所有类别推荐均为付费推广。

## 安装

1. 点击 GitHub 页面上的 **Code → Download ZIP**，解压并把文件夹放在长期保留的位置；也可以克隆仓库。
2. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
3. 点“加载已解压的扩展程序”，选择 `bilibili-promo-replacer` 或 `zhihu-cleaner` 文件夹，文件夹内应直接包含 `manifest.json`。
4. 要使用两个插件，分别加载这两个文件夹。
5. 刷新对应网站。

更新源码后，在扩展管理页点击对应插件的重新加载按钮，再刷新网站。请保留加载时选择的文件夹。

## 知乎赞同提示

“航海家 ×× 等 653 人赞同”显示为“653 人赞同”，人数随页面更新。普通赞同按钮、数量、作者和正文保留。

## 说明

- 仅在各插件 Manifest 指定的网站运行；无需编译或额外服务器。
- 扩展只处理页面显示，不执行点赞或取消点赞，不上传数据。
- 视觉替换不阻止网站加载原广告资源，也不解锁付费内容。
- 网站结构变化可能需要更新识别规则。

插件各自的加载说明、源码、测试和验证范围见对应目录。知乎 1.0.3 已通过 18 项本地 Chrome DOM 测试；用户登录后的航海家真实页面样式尚未验证。B 站已有验证记录见 [VERIFICATION.txt](bilibili-promo-replacer/VERIFICATION.txt)。
