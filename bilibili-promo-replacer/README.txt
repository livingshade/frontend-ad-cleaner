B站推广替换 v1.2.0

效果
- B 站带平台推广标识的视频：封面和标题替换为「广告」。
- 直播、番剧、国创、综艺、课堂、电影、电视剧、纪录片、漫画推荐：
  封面和标题替换为「广告：类别」，例如「广告：漫画」。
- 保留卡片位置与原链接，普通视频正常显示。
- 这些类别的「广告：」前缀按用户偏好显示，不代表它们全部属于付费推广。

安装
1. 将压缩包解压到长期保留的文件夹。
2. Chrome 地址栏输入 chrome://extensions。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择 bilibili-promo-replacer 文件夹，其中应直接包含 manifest.json。
5. 刷新 B 站页面。

更新
文件更新后，在扩展管理页点击「B站推广替换」的圆形箭头「重新加载」，
再刷新 B 站页面。当前最新版本为 1.2.0。

暂停或卸载
在扩展管理页关闭或移除「B站推广替换」，然后刷新 B 站。
安装后请保留整个文件夹，删除或移动可能导致扩展失效。

适用范围
仅在 www.bilibili.com 和 search.bilibili.com 内运行。
支持 bili-video-card 视频卡片与 floor-single-card 类别推荐卡片。
推广依据为平台推广元素、封面统计区的「广告／推广」文字，或主封面、
标题链接使用 B 站官方广告跳转地址；不根据标题关键词猜测软广。
类别卡片依据原有的类别徽标处理。频道导航与顶部轮播保持原样。
不处理播放器内的贴片广告，不识别口播或未标注的植入广告。
这是视觉替换，原封面仍可能被 B 站加载。页面改版时可能需要适配。

隐私
不额外联网，不读取 Cookie，不上传数据，不保存浏览历史。
不需要服务器、API Key 或付费服务。

开发与验证
25 项自动行为测试通过。安装文件与测试源码一致。
普通使用不需要开发工具；修改代码时使用 Node.js 24、npm install、
npm test 和 npm run lint。tests/ 为测试，preview/ 为广告替换示例。
根目录与 extension/ 都可加载，选择一种安装即可，不要重复安装。
