# 知乎推广替换 1.0.3

把知乎明确标记的广告、推广及盐选卡片显示为灰色“广告”占位，隐藏原标题、封面和摘要。有可用链接时，点击“广告”仍进入原链接。

隐藏航海家入口和标记，将回答顶部“航海家 ×× 等 653 人赞同”显示为“653 人赞同”，人数随页面更新。保留普通点赞／赞同按钮、数量、普通赞同摘要，以及问题、回答、评论正文、收藏和回复。支持滚动加载、页面内导航和卡片重新渲染。

## Mac 上更新现有扩展

用仓库内 `zhihu-cleaner` 文件夹的最新源码更新你加载扩展时选择的目录。

1. 在 Chrome 打开 `chrome://extensions`，找到“知乎推广替换”。
2. 点该扩展卡片上的重新加载按钮（圆形箭头）。
3. 刷新知乎标签页。刷新后普通赞同按钮和数量会恢复，顶部赞同提示显示人数并去掉航海家推荐信息。

如果更换了扩展文件夹的位置，请移除旧扩展，再按下方步骤加载新的 `zhihu-cleaner` 文件夹。

## 首次加载到 Chrome（Windows / macOS）

1. 解压 `zhihu-cleaner-1.0.3.zip`，把 `zhihu-cleaner` 文件夹放在一个长期保留的位置。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”，点“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的 **zhihu-cleaner 文件夹**。
5. 刷新已经打开的知乎页面，即可生效。

不需要编译、安装 Node.js 或登录任何额外服务。不要直接把 ZIP 拖入扩展管理页。升级后在扩展管理页点“重新加载”，再刷新知乎。停用或移除扩展后，刷新知乎即可恢复原页面。

## 识别范围

- 信息流广告、常见侧栏广告、显式 `is_ad` 标记。
- 盐选专属标记、盐选推荐卡片、标题直接指向盐选内容的卡片。
- 普通正文里提及“广告”“盐选”“航海家”，或正文引用盐选链接，不会据此把整篇回答当成广告。
- 嵌在普通正文里的盐选推荐小卡片，仅替换该小卡片。
- 正常用户昵称叫“航海家”时，保留昵称。

只在 `zhihu.com` 及其子域名的网页运行。扩展没有后台服务、网络请求、数据上传或外部依赖，不执行点赞、取消点赞或其他账号操作。这是显示层处理，不阻止知乎自身下载广告资源，也不解锁付费内容。

知乎会调整页面结构；无法识别的新样式会保留，避免凭正文关键词误删。当前用户登录状态下的航海家提示及个性化广告未实测，具体验证范围见 `VALIDATION.md`。

## 开发与测试

`content.js` 集中维护识别规则，`content.css` 负责占位和隐藏，`manifest.json` 限定域名。所有代码随包提供。

可直接在 Chrome 打开 `tests/browser.html` 查看本地 DOM 回归测试。自动运行需 Node.js：

```powershell
node tests/run.mjs
```

Windows 默认查找标准 Chrome 安装路径。其他位置或系统请设置 `CHROME_PATH`，例如 macOS：

```sh
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node tests/run.mjs
```

测试使用独立临时浏览器配置和虚构页面，不读取日常 Chrome 配置。测试结果写入 `tests/latest-results.json`。不需要 npm 依赖。
